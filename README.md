`Solidity` `Ethereum` `IPFS` `React` `REST APIs`

### [Aana](https://github.com/kevaleaditya1/Aana) · [Live site](https://aana-tech.vercel.app)
**A home for writing about technology.** A full-stack publishing platform for emerging tech, AI, and gadgets, built with typed APIs and a PostgreSQL-backed content workflow.

`TypeScript` `Hono` `PostgreSQL` `Prisma` `React`

### [Detectify](https://github.com/kevaleaditya1/pneumonia-detection)
**Computer vision for chest X-rays.** A convolutional neural network project for pneumonia detection, with image preprocessing, augmentation, OpenCV classification, and training-metric analysis.

`Python` `CNN` `OpenCV` `Computer Vision`

### [Musify](https://github.com/kevaleaditya1/Musify)
**Music recommendations shaped by expression.** A webcam-based emotion recognition project that connects CNN predictions to personalized music playback.

`Python` `CNN` `OpenCV` `Tkinter`

## How I approach building

I'm especially interested in the parts of software where data, models, and useful products meet. My projects have taken me from preparing image datasets and evaluating CNNs to designing REST APIs, relational schemas, and blockchain-backed verification flows.

I like making the underlying system understandable as well as making the interface useful: what data goes in, what the system decides, and how someone can trust the result.
